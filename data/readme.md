## Welding Data Set 분석

1. 라벨 구조 : 개별 용접(11,939건) 라벨이 없음. result 시트는 날짜 × 불량유형별 개수(파임·용접부족·크랙)뿐 - 라벨링을 직접 해야하는지에 대한 의문
   
2. 불량 규모 : 라벨 있는 8일간 불량 총 39건, 약 0.38% - 불량 데이터가 매우 적은 문제

3. 3/27일 : 라벨 있는 8일간 불량 총 39건 (약 0.38%), 하지만 3/27일 데이터는 아무 정보 없음. 불량 데이터 전체를 준 것이 아닌지에 대한 의문. 3/31 데이터에는 type3 defect 가 없음.

4. 두께/설비/품목 : 모두 한가지로 고정되어 있어 input으로의 역할을 할 수 없음.

5. 공정 유형 : 저항 점용접을 사용한 결과 데이터로 확인됨. Q = I²Rt = V·I·t 과 같은 관계식을 알고리즘에 적용해볼 수 있겠음.
